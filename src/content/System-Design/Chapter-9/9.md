# Interview Questions & Solutions

## Question 1

### Question

Why did containers become more popular than Virtual Machines?

### Ideal Answer

Containers share the host operating system kernel, making them much lighter and faster than virtual machines. They provide consistent environments across development, testing, and production while enabling higher resource utilization.

---

## Question 2

### Question

What is the difference between a Docker Image and a Docker Container?

### Ideal Answer

A Docker Image is an immutable template containing the application and its dependencies. A Docker Container is a running instance of that image.

---

## Question 3

### Question

What problem does Kubernetes solve?

### Ideal Answer

Kubernetes automates deployment, scaling, networking, health monitoring, and recovery of containers. It allows applications to run reliably across clusters without manual infrastructure management.

---

## Question 4

### Question

Compare Rolling Update, Blue-Green, and Canary deployments.

### Ideal Answer

Rolling Updates gradually replace old instances with new ones. Blue-Green deployments maintain two identical environments and switch traffic instantly. Canary deployments release changes to a small percentage of users first, allowing production validation before full rollout.

---

## Question 5 (FAANG)

### Question

Design the deployment pipeline for a global e-commerce platform.

### Ideal Answer

Developers push code to Git, triggering a CI/CD pipeline that runs automated tests, builds Docker images, scans for vulnerabilities, and pushes images to a registry. Kubernetes performs rolling or canary deployments, monitored by Prometheus and Grafana. Health checks determine rollout success, while feature flags allow controlled feature activation without redeployment. GitOps tools such as ArgoCD synchronize infrastructure with Git repositories.

# Revision Notes

- Containers solve environment consistency problems.
- Docker packages applications into immutable images.
- Kubernetes orchestrates containers at scale.
- Pods are the smallest deployable Kubernetes units.
- Services provide stable networking despite changing Pod IPs.
- Rolling Updates, Blue-Green, and Canary each serve different deployment needs.

- Infrastructure as Code enables repeatable cloud infrastructure.
