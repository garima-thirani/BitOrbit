# Interview Questions & Solutions

## Question 1

### Question

Why are stateless services preferred in Microservices?

### Ideal Answer

Stateless services allow any instance to process any request because no client session is stored in local memory. This simplifies horizontal scaling, failover, and load balancing.

---

## Question 2

### Question

When should you use horizontal scaling instead of vertical scaling?

### Ideal Answer

Horizontal scaling is preferred for cloud-native applications because it improves availability, supports virtually unlimited growth, and avoids hardware limits. Vertical scaling is useful for components like databases where scaling out is more difficult.

---

## Question 3

### Question

How does caching improve performance?

### Ideal Answer

Caching stores frequently accessed data in memory, reducing expensive database queries and lowering latency. A high cache hit ratio significantly improves throughput while reducing infrastructure costs.

---

## Question 4

### Question

Explain the different types of performance testing.

### Ideal Answer

Load testing validates expected traffic, stress testing identifies breaking points, spike testing evaluates sudden traffic surges, and soak testing detects long-running issues such as memory leaks and resource exhaustion.

---

## Question 5 (FAANG)

### Question

Design the scaling strategy for a global e-commerce platform expected to handle 20× traffic during Black Friday.

### Ideal Answer

Use stateless services behind load balancers with Kubernetes Horizontal Pod Autoscalers. Cache frequently accessed data in Redis, offload background processing to Kafka, pool database connections, compress responses, paginate large datasets, and continuously monitor latency, throughput, cache hit ratios, and queue lengths. Load-test the platform before the event and use canary deployments for last-minute releases to minimize operational risk.

# Revision Notes

- Latency measures response time; throughput measures work completed.
- Prefer horizontal scaling for cloud-native Microservices.
- Design services to be stateless whenever possible.
- Caching is often the highest-impact performance optimization.
- Reuse expensive resources through connection and thread pools.
- Use asynchronous processing to shorten critical request paths.
- Benchmark before optimizing and optimize the actual bottleneck.
- Performance engineering is as much about cost optimization as it is about speed.
