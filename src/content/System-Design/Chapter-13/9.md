# FAANG Interview Questions

## Question 1

### Question

How do large companies choose indexes?

### Ideal Answer

Large companies design indexes based on real query patterns, execution plans, and production monitoring. They continuously measure index usage, remove redundant indexes, and optimize for the highest-impact workloads.

---

## Question 2

### Question

Why are covering indexes so valuable?

### Ideal Answer

Covering indexes allow queries to be answered entirely from the index without accessing the base table, reducing disk I/O and significantly improving latency for frequently executed queries.

---

## Question 3

### Question

How do companies handle heavy read workloads?

### Ideal Answer

They combine efficient indexing with read replicas, caching layers, keyset pagination, and optimized execution plans to distribute traffic and reduce load on the primary database.

---

## Question 4

### Question

How is query performance monitored in production?

### Ideal Answer

Production systems continuously monitor slow query logs, execution plans, index usage, fragmentation, cache hit ratios, CPU utilization, memory consumption, and query latency. Automated alerts notify engineers when performance regresses.

---

## Question 5 (FAANG)

### Question

Design the indexing strategy for a global marketplace serving hundreds of millions of users.

### Ideal Answer

Use clustered indexes for primary keys, composite indexes for common multi-column queries, covering indexes for high-frequency reads, full-text indexes for search, read replicas for reporting, materialized views for analytics, automatic statistics updates, periodic index maintenance, slow query monitoring, execution plan analysis, and continuous index tuning based on production workloads.
