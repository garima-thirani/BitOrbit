# Interview Questions & Solutions

## Question 1

### Question

What is a Cost-Based Optimizer?

### Ideal Answer

A Cost-Based Optimizer evaluates multiple execution plans and estimates their resource costs using statistics such as row counts, selectivity, and histograms. It chooses the plan with the lowest estimated cost.

---

## Question 2

### Question

What information does EXPLAIN provide?

### Ideal Answer

EXPLAIN shows the database's execution plan, including whether indexes are used, join algorithms, estimated row counts, scan types, sorting operations, and estimated execution costs.

---

## Question 3

### Question

Why are accurate statistics important?

### Ideal Answer

Statistics allow the optimizer to estimate how many rows each operation will process. Incorrect estimates may cause inefficient plans such as unnecessary table scans or suboptimal join algorithms.

---

## Question 4

### Question

When is a Hash Join preferable to a Nested Loop Join?

### Ideal Answer

Hash Joins perform well when joining large, unsorted datasets because they build an in-memory hash table for efficient lookups. Nested Loop Joins are more suitable when one table is small or indexed.

---

## Question 5 (FAANG)

### Question

A query that used to run in 20 ms now takes 8 seconds. How would you investigate?

### Ideal Answer

Begin by examining the execution plan using EXPLAIN ANALYZE. Compare estimated versus actual row counts, verify whether indexes are being used, inspect join algorithms, check for table scans or expensive sorts, ensure database statistics are current, identify recent schema or data changes, and review whether index fragmentation or missing indexes are contributing to the regression.

# Revision Notes

- Every SQL query is parsed, optimized, planned, and executed.
- Modern databases use Cost-Based Optimizers rather than fixed rules.
- EXPLAIN and EXPLAIN ANALYZE are essential tools for understanding query execution.
- Accurate statistics and cardinality estimates are critical for good execution plans.
- Index Seeks are preferred over Index Scans and Table Scans.
- Nested Loop, Hash Join, and Merge Join each have different performance characteristics.
- Reading execution plans is a core skill for diagnosing database performance issues.
