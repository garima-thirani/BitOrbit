# Interview Questions & Solutions

## Question 1

### Question

Why is Kafka more than a traditional message queue?

### Ideal Answer

Kafka stores events as an immutable distributed log with configurable retention, allowing multiple consumers to independently replay and process the same events. Traditional queues typically remove messages after successful consumption.

---

## Question 2

### Question

Why are Kafka topics divided into partitions?

### Ideal Answer

Partitions enable horizontal scalability by allowing producers and consumers to process data in parallel. Ordering is guaranteed within each partition, while multiple partitions increase throughput.

---

## Question 3

### Question

What is a consumer group?

### Ideal Answer

A consumer group is a set of consumers that cooperatively process messages from a topic. Each partition is assigned to only one consumer within the group, ensuring that each event is processed once per consumer group.

---

## Question 4

### Question

What is the purpose of Kafka offsets?

### Ideal Answer

Offsets uniquely identify each event within a partition and allow consumers to track their progress. If a consumer fails, it can resume processing from the last committed offset.

---

## Question 5 (FAANG)

### Question

Design an event streaming platform for a global video streaming service.

### Ideal Answer

Use Kafka clusters with multiple brokers and replicated partitions. Partition playback events by user ID to preserve ordering for each user while enabling parallel processing. Deploy multiple consumer groups for recommendations, analytics, billing, monitoring, and machine learning. Enable replication, configure appropriate retention periods, use `acks=all` for critical events, monitor consumer lag and broker health, and scale partitions and consumers as traffic grows.

# Revision Notes

- Kafka is a distributed event streaming platform built around an immutable log.
- Brokers store topics, which are divided into partitions for scalability.
- Producers publish events to topics, while consumers read them independently.
- Consumer groups distribute partitions among multiple consumers for parallel processing.
- Offsets allow consumers to resume processing after failures.
- Replication provides fault tolerance and high availability.
- Retention enables replay of historical events for new or recovering consumers.
