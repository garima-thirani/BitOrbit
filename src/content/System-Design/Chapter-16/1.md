| Synchronous | Asynchronous |

| Simpler | More Scalable |

# Engineering Notes

## Queues Trade Immediate Execution for Scalability

Instead of

forcing

every request

to complete

immediately,

queues

allow systems

to acknowledge work

quickly

and process

it later.

This improves

throughput,

availability,

and user experience,

especially

during traffic spikes.

---

## Decoupling Is One of the Biggest Benefits

Without queues,

services

must know

whether

other services

are available.

With queues,

producers

simply publish work,

and consumers

process it

whenever

they are ready.

This loose coupling

makes systems

far easier

to scale,

maintain,

and recover

from failures.

# Interview Questions & Solutions

## Question 1

### Question

Why are message queues used in distributed systems?

### Ideal Answer

Message queues decouple services, enable asynchronous processing, absorb traffic spikes, improve fault tolerance, and increase scalability by allowing producers and consumers to operate independently.

---

## Question 2

### Question

What is the difference between synchronous and asynchronous communication?

### Ideal Answer

In synchronous communication, the sender waits until the receiver completes processing before continuing. In asynchronous communication, the sender places work into a queue and continues immediately while background consumers process the task later.

---

## Question 3

### Question

Why do queues improve scalability?

### Ideal Answer

Queues act as buffers between producers and consumers, smoothing sudden traffic spikes and allowing consumers to process work at a sustainable rate. Additional consumers can be added horizontally to increase throughput.

---

## Question 4

### Question

What is a competing consumer pattern?

### Ideal Answer

Multiple workers consume messages from the same queue. Each message is processed by only one worker, enabling parallel processing and automatic load distribution.

---

## Question 5 (FAANG)

### Question

Design the order processing system for a global e-commerce platform using message queues.

### Ideal Answer

The order service publishes an order message to a durable queue after validating payment. Independent consumer services process inventory reservation, shipping, notifications, analytics, and recommendation updates asynchronously. Implement retries, dead-letter queues, monitoring, horizontal worker scaling, idempotent processing, and message acknowledgments to ensure reliability and scalability under heavy traffic.

# Revision Notes

- Message queues enable asynchronous communication between services.
- Producers create messages, queues store them, and consumers process them.
- Queues decouple services and improve scalability.
- FIFO processing preserves message order when required.
- Queues absorb traffic spikes through buffering.
- Horizontal scaling is achieved by adding more consumer workers.
- Monitoring queue length, throughput, and latency is essential for production systems.
