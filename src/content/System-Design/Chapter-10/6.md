# Engineering Notes

The purpose

Its primary purpose

Modern systems

# Interview Questions & Solutions

## Question 1

### Question

Why is modulo hashing unsuitable for distributed systems?

### Ideal Answer

Modulo hashing depends on the total number of servers. When servers are added or removed, almost every key maps to a different server, causing massive data movement and expensive rebalancing.

---

## Question 2

### Question

How does consistent hashing reduce rebalancing?

### Ideal Answer

Both servers and keys are placed on a hash ring. When a server joins or leaves, only the keys belonging to the affected region of the ring are redistributed, while the rest of the data remains unchanged.

---

## Question 3

### Question

What are virtual nodes?

### Ideal Answer

Virtual nodes map multiple logical positions on the hash ring to a single physical server. They improve load balancing, reduce hotspots, simplify scaling, and minimize data movement during rebalancing.

---

## Question 4

### Question

What is a Distributed Hash Table?

### Ideal Answer

A Distributed Hash Table (DHT) is a distributed key-value storage system that uses consistent hashing to determine which node owns a particular key. It supports efficient lookup, insertion, and deletion while scaling across many machines.

---

## Question 5 (FAANG)

### Question

Design the key distribution mechanism for a distributed cache supporting thousands of servers.

### Ideal Answer

Use consistent hashing with virtual nodes to distribute keys evenly across cache servers. Replicate keys onto successor nodes for fault tolerance. Monitor node utilization to detect imbalance, automatically rebalance virtual nodes during scaling events, and route requests using the hash ring. This minimizes cache misses and data movement when servers join or leave the cluster.

# Revision Notes

- Traditional modulo hashing requires large-scale data movement when cluster size changes.
- Consistent hashing maps both keys and servers onto a circular hash ring.
- Keys are assigned to the next server in the clockwise direction.
- Virtual nodes improve load balancing and simplify rebalancing.
- Replication enhances availability and durability.
- Distributed Hash Tables build scalable key-value storage on top of consistent hashing.
- Consistent hashing is a cornerstone of modern distributed storage systems such as Cassandra and Dynamo.
