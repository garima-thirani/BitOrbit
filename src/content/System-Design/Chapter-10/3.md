# Interview Questions & Solutions

## Question 1

### Question

What is the difference between Strong Consistency and Eventual Consistency?

### Ideal Answer

Strong consistency guarantees that every read returns the latest successful write immediately. Eventual consistency allows temporary stale reads but guarantees that all replicas will converge if no new updates occur. Strong consistency prioritizes correctness, while eventual consistency prioritizes availability and scalability.

---

## Question 2

### Question

Explain Linearizability.

### Ideal Answer

Linearizability guarantees both the latest value and real-time ordering of operations. If one operation completes before another begins, every client must observe them in that order. It is one of the strongest practical consistency guarantees.

---

## Question 3

### Question

What is Read-after-Write Consistency?

### Ideal Answer

After a client successfully writes data, its subsequent reads are guaranteed to return the updated value. This provides a good user experience without requiring global strong consistency.

---

## Question 4

### Question

What is a Quorum?

### Ideal Answer

A quorum defines how many replicas must participate in reads and writes. When R + W > N, read and write sets overlap, allowing systems to provide strong consistency while replicating data across multiple nodes.

---

## Question 5 (FAANG)

### Question

Design the consistency strategy for a global e-commerce platform.

### Ideal Answer

Use strong consistency for payments, inventory reservations, and authentication because correctness is critical. Use read-after-write consistency for user profiles, causal consistency for messaging features, and eventual consistency for recommendations, search indexing, notifications, analytics, and product reviews. Configure quorum reads and writes where appropriate to balance latency and consistency based on business requirements.

# Revision Notes

- Consistency models define what guarantees readers receive after writes.
- Strong consistency always returns the latest data.
- Eventual consistency favors scalability and availability.
- Linearizability adds real-time ordering guarantees.
- Causal consistency preserves cause-and-effect relationships.
- Read-after-write and session consistency improve user experience.
- Quorum-based systems balance consistency and performance through configurable read/write thresholds.
- Choose the weakest consistency model that still satisfies business requirements.
