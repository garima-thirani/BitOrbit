# 25 One-Line FAANG Revision Facts

1. Kafka is a distributed append-only log.
2. RabbitMQ routes through Exchanges.
3. Pulsar separates compute and storage.
4. Events are immutable.
5. Commands express intent; events express facts.
6. Consumer Groups enable parallelism.
7. Ordering is guaranteed only within a Kafka partition.
8. Idempotency makes retries safe.
9. DLQs isolate poison messages.
10. Schema Registries prevent breaking changes.
11. CQRS separates reads and writes.
12. Event Sourcing stores history instead of state.
13. Snapshots reduce replay time.
14. Flink excels at stateful stream processing.
15. Kafka Streams runs inside your application.
16. Watermarks handle late-arriving events.
17. Sliding windows overlap; tumbling windows do not.
18. At-least-once is the most common delivery guarantee.
19. Exactly-once is expensive but critical for finance.
20. Pub/Sub broadcasts events to multiple consumers.
21. Queue depth measures pending work.
22. Consumer lag measures processing delay.
23. Replication provides fault tolerance.
24. Exponential backoff with jitter prevents retry storms.
25. Loose coupling is the primary benefit of messaging.
