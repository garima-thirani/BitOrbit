# Interview Questions & Solutions

## Question 1

### Question

What is Event Sourcing?

### Ideal Answer

Event Sourcing is a persistence pattern where every state change is stored as an immutable event instead of storing only the latest state. Current application state is reconstructed by replaying these events.

---

## Question 2

### Question

Why are snapshots used in Event Sourcing?

### Ideal Answer

Without snapshots, rebuilding state requires replaying every historical event, which becomes slow for long event streams. Snapshots periodically store the current state so only recent events need to be replayed.

---

## Question 3

### Question

What is CQRS?

### Ideal Answer

CQRS separates command handling (writes) from query handling (reads). The write model focuses on business correctness, while the read model is optimized for fast queries and reporting.

---

## Question 4

### Question

What are projections?

### Ideal Answer

Projections transform events into optimized read models such as dashboards, search indexes, reports, or materialized views. They enable efficient queries without affecting the write model.

---

## Question 5 (FAANG)

### Question

Design the persistence layer for a global digital banking platform.

### Ideal Answer

Implement Event Sourcing with an append-only event store to capture all financial transactions. Commands validate business rules and generate immutable events. Build CQRS read models using projections for account balances, customer dashboards, and reporting. Use snapshots to accelerate account reconstruction, version events for backward compatibility, ensure idempotent event processing, and replicate the event store across regions for high availability and disaster recovery.

# Revision Notes

- Event Sourcing stores immutable events instead of only the latest state.
- Current state is reconstructed through event replay.
- Snapshots reduce replay time for long event streams.
- CQRS separates command handling from query handling.
- Projections create optimized read models from event streams.
- Materialized views provide fast query performance.
- Event Sourcing and CQRS are especially valuable for financial systems, auditing, analytics, and complex distributed applications.
