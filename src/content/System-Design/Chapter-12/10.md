# 30 One-Line FAANG Revision Facts

1. Cache avoids repeated database work.
2. RAM is thousands of times faster than disk.
3. Cache-Aside is the most common pattern.
4. Write-Through prioritizes consistency.
5. Write-Back prioritizes write performance.
6. Refresh-Ahead improves hit ratio.
7. TTL prevents stale data.
8. LRU exploits temporal locality.
9. LFU keeps frequently accessed objects.
10. Redis supports rich data structures.
11. Memcached stores simple key-value pairs.
12. Browser cache eliminates server requests.
13. CDN reduces geographic latency.
14. Reverse proxies cache backend responses.
15. Databases remain the source of truth.
16. Event-driven invalidation scales well.
17. Versioning prevents stale overwrites.
18. Redis Cluster uses 16,384 hash slots.
19. Consistent hashing minimizes key movement.
20. Virtual nodes improve load balancing.
21. Replication provides fault tolerance.
22. Hot keys overload individual cache nodes.
23. Cache stampedes overwhelm databases.
24. Random TTL prevents synchronized expiration.
25. Bloom Filters stop invalid requests.
26. Cache warming improves cold starts.
27. Request coalescing reduces duplicate work.
28. Multi-level caching is standard in production.
29. Monitor hit ratio continuously.
30. Good caching is workload-dependent.
