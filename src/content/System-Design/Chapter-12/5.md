# Interview Questions & Solutions

## Question 1

### Question

Why is Redis so fast?

### Ideal Answer

Redis stores data in memory, uses efficient data structures, processes commands through a lightweight event loop, avoids lock contention with single-threaded command execution, and uses a simple network protocol, enabling extremely low-latency operations.

---

## Question 2

### Question

What is the difference between RDB and AOF persistence?

### Ideal Answer

RDB periodically saves snapshots of the dataset, providing fast recovery with possible data loss between snapshots. AOF logs every write operation, offering better durability at the cost of larger files and slower recovery.

---

## Question 3

### Question

When should you use a Redis Sorted Set?

### Ideal Answer

Sorted Sets are ideal when data must remain ordered by score, such as leaderboards, rankings, trending content, or priority queues.

---

## Question 4

### Question

What is Redis Sentinel?

### Ideal Answer

Redis Sentinel provides high availability by monitoring Redis instances, detecting failures, automatically promoting a replica to primary, and notifying clients about topology changes.

---

## Question 5 (FAANG)

### Question

Design the Redis architecture for a global social media platform.

### Ideal Answer

Use Redis Cluster for horizontal scaling and automatic sharding. Store sessions as Strings, user profiles as Hashes, feeds with Sorted Sets, notifications in Lists, and analytics using HyperLogLog. Configure AOF with periodic RDB snapshots for durability, deploy Sentinel or Cluster failover for high availability, monitor memory usage, hit ratio, replication lag, and latency, and define TTL policies for temporary data such as sessions and caches.

# Revision Notes

- Redis is an in-memory key-value data structure server optimized for low latency.
- It supports multiple data structures including Strings, Lists, Hashes, Sets, Sorted Sets, Bitmaps, HyperLogLog, and Streams.
- Redis primarily executes commands through a single-threaded event loop, avoiding lock contention.
- RDB provides snapshot-based persistence, while AOF provides append-only durability.
- Sentinel enables automatic failover, and Redis Cluster enables horizontal scaling through hash slots.
- Choosing the correct data structure is essential for both performance and memory efficiency.
