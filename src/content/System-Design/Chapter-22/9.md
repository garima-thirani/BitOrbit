# Case Study 1 — ChatGPT Architecture

ChatGPT is one of the most well-known AI systems today.

Although its internal implementation is proprietary,

its high-level architecture follows patterns common across modern LLM platforms.

---

# What Happens When You Ask ChatGPT a Question?

Suppose you type

```text
Explain Kubernetes like I'm a beginner.
```

The request flows through several stages.

```text
User

↓

Authentication

↓

API Gateway

↓

Rate Limiting

↓

Prompt Processing

↓

Context Assembly

↓

Model Selection

↓

Inference

↓

Safety Checks

↓

Streaming Response

↓

User
```

---

# High-Level Architecture

```text
              User
                │
                ▼
         Web / Mobile App
                │
                ▼
          API Gateway
                │
                ▼
     Authentication & Billing
                │
                ▼
      Prompt Processing Layer
                │
                ▼
       Model Routing Layer
                │
                ▼
      Large Language Model
                │
                ▼
      Output Guardrails
                │
                ▼
       Streaming Response
```

Notice that

the LLM

is only one component.

Most engineering effort happens around it.

---

# Why Streaming Responses?

Instead of waiting

10 seconds

for an entire answer,

ChatGPT streams tokens

as they are generated.

This reduces

perceived latency

and improves user experience.

---

# Real-Life Analogy

Imagine a teacher answering a question.

The teacher doesn't stay silent

for five minutes

and then suddenly speak.

Instead,

they begin explaining immediately.

Streaming works similarly.

# Case Study 2 — GitHub Copilot

GitHub Copilot is an AI coding assistant.

Unlike ChatGPT,

its primary goal is

understanding source code.

---

# Problem

Suppose a developer types

```python
connect_to_database()
```

The AI cannot generate useful code

without understanding

the surrounding project.

It must first retrieve context.

---

# Architecture

```text
Developer

↓

IDE Extension

↓

Project Analysis

↓

Retrieve Nearby Files

↓

Embedding Search

↓

Prompt Construction

↓

LLM

↓

Code Completion
```

---

# Context Retrieval

GitHub Copilot collects

- Current File
- Open Tabs
- Nearby Functions
- Project Structure
- Imported Libraries

Only then

is the prompt sent

to the LLM.

Without context,

code quality would be poor.

---

# Why RAG Matters

GitHub Copilot is essentially

a production RAG system.

The retrieved code

acts as context

for generation.

---

# Real-Life Analogy

Imagine asking

a senior developer

to review code.

They first read

the existing project

before suggesting changes.

Copilot behaves similarly.

# Architectural Lessons

Across every case study,

certain patterns repeatedly appear.

Modern AI systems almost always include

- Authentication
- API Gateway
- Embedding Models
- Vector Databases
- Retrieval Pipelines
- Model Routing
- Inference Servers
- Safety Layers
- Observability
- Cost Monitoring

The AI model

is rarely the entire system.

It is simply

one component

inside a much larger platform.

# Key Takeaways

- Modern AI products are built using combinations of LLMs, Vector Databases, Retrieval Pipelines, AI Infrastructure, and Observability.
- ChatGPT focuses on conversational AI using optimized inference infrastructure and streaming responses.
- GitHub Copilot uses Retrieval-Augmented Generation (RAG) to understand project context before generating code.
- Perplexity AI combines web search with LLMs to provide grounded, up-to-date answers.
- Cursor IDE extends LLM capabilities through AI Agent workflows involving planning, code analysis, and tool usage.
- Netflix Recommendation Systems primarily use traditional Machine Learning models rather than LLMs.
- Spotify relies heavily on embeddings and similarity search to recommend music.
- Amazon combines embeddings, collaborative filtering, and ranking models to generate personalized product recommendations.
- Despite serving different purposes, these systems share common architectural building blocks such as retrieval, ranking, model serving, and monitoring.
