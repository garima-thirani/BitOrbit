# Interview Questions & Solutions

## Question 1

### Question

Why are global databases needed?

### Ideal Answer

Global databases reduce user latency by storing and serving data from regions geographically close to users while maintaining replication across multiple locations for availability and disaster recovery.

---

## Question 2

### Question

What is the difference between Active-Active and Active-Passive architectures?

### Ideal Answer

Active-Active allows multiple regions to process writes simultaneously, improving availability but requiring conflict resolution. Active-Passive designates a single write region with other regions acting as replicas, simplifying consistency at the cost of write latency for distant users.

---

## Question 3

### Question

Why is asynchronous replication commonly used across continents?

### Ideal Answer

Synchronous replication across long distances significantly increases write latency because acknowledgments must travel between continents. Asynchronous replication provides much lower latency while offering eventual consistency.

---

## Question 4

### Question

What is data residency?

### Ideal Answer

Data residency refers to legal or regulatory requirements that certain data must remain stored within specific geographic regions or countries, such as GDPR requirements in Europe.

---

## Question 5 (FAANG)

### Question

Design the database architecture for a global social media platform with users in over 100 countries.

### Ideal Answer

Deploy regional database clusters using geo-sharding so users primarily access nearby data. Use asynchronous cross-region replication for user profiles, posts, and timelines while reserving strong consistency for security-sensitive operations. Route requests through a global load balancer, implement regional failover, monitor replication lag, comply with regional data residency laws, and use caching and CDNs to minimize latency worldwide.

# Revision Notes

- Global databases reduce latency by placing data close to users.
- Geo-sharding partitions data by geographic location.
- Active-Active architectures improve availability but require conflict resolution.
- Active-Passive architectures simplify consistency but centralize writes.
- Asynchronous replication is commonly used across continents to reduce latency.
- Data residency laws influence where user data may be stored.
- Regional failover and disaster recovery are essential for globally distributed systems.
