# Interview Questions & Solutions

## Question 1

### Question

Why is Redis significantly faster than traditional databases?

### Ideal Answer

Redis stores data entirely in memory, avoiding disk I/O for most operations. It also uses simple data structures, an event-driven architecture, and efficient O(1) operations without SQL parsing or query optimization overhead.

---

## Question 2

### Question

What is the difference between RDB and AOF persistence?

### Ideal Answer

RDB periodically saves snapshots of the entire dataset, providing fast recovery and compact storage but allowing some recent data loss. AOF logs every write operation, offering greater durability at the cost of larger files and slower recovery.

---

## Question 3

### Question

What problem does Redis Sentinel solve?

### Ideal Answer

Redis Sentinel monitors Redis instances, detects failures, performs automatic failover by promoting replicas to primary, and updates clients with the new topology to maintain high availability.

---

## Question 4

### Question

Why does Redis Cluster use hash slots instead of simple consistent hashing?

### Ideal Answer

Redis Cluster maps keys to one of 16,384 hash slots, which are assigned to nodes. During scaling, only hash slots are reassigned rather than recalculating ownership for every key, making rebalancing simpler and more predictable.

---

## Question 5 (FAANG)

### Question

Design a Redis architecture for a global e-commerce platform serving 100 million users.

### Ideal Answer

Deploy Redis Cluster for horizontal scalability using hash slots, replicate each primary with multiple replicas for high availability, use Sentinel or cluster failover mechanisms, enable hybrid persistence with RDB and AOF, cache sessions, product catalogs, and recommendation data, monitor memory usage and replication lag, and distribute clients across regions with local Redis clusters backed by multi-region disaster recovery.

# Revision Notes

- Redis is an in-memory data store optimized for extremely low-latency operations.
- Redis supports rich data structures including Strings, Hashes, Lists, Sets, Sorted Sets, Streams, Bitmaps, HyperLogLog, and Geo indexes.
- Most Redis commands execute in O(1) time.
- RDB provides snapshot-based persistence, while AOF provides log-based durability.
- Redis replication improves availability and read scalability.
- Redis Sentinel automates health monitoring and failover.
- Redis Cluster uses 16,384 hash slots to distribute data across multiple nodes for horizontal scalability.
