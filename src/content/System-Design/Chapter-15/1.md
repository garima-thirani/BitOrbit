# Interview Questions & Solutions

## Question 1

### Question

Why is caching important?

### Ideal Answer

Caching stores frequently accessed data in fast memory, reducing database load, lowering latency, increasing throughput, and improving overall system scalability.

---

## Question 2

### Question

What is the difference between a cache hit and a cache miss?

### Ideal Answer

A cache hit occurs when requested data is already available in the cache and can be returned immediately. A cache miss occurs when the data is absent, requiring a database lookup before the result is cached for future requests.

---

## Question 3

### Question

Why is RAM preferred for caching?

### Ideal Answer

RAM offers nanosecond-level access times, making it thousands of times faster than disk-based storage. This significantly reduces response latency for frequently accessed data.

---

## Question 4

### Question

What is a cache hit ratio?

### Ideal Answer

The cache hit ratio measures the percentage of requests served directly from the cache. It is calculated as Hits ÷ (Hits + Misses). Higher hit ratios indicate more effective caching.

---

## Question 5 (FAANG)

### Question

A product page receives one million requests per minute but changes only once every hour. How would you optimize it?

### Ideal Answer

Cache the product metadata in a distributed cache such as Redis with an appropriate TTL or event-driven invalidation strategy. Serve requests directly from the cache, update the cache whenever the product changes, monitor cache hit ratios, and use a CDN for static assets like images to further reduce backend load.

# Revision Notes

- A cache stores frequently accessed data in fast memory.
- Cache hits are significantly faster than cache misses.
- High cache hit ratios reduce latency and database load.
- Modern systems use multiple cache layers simultaneously.
- Distributed caches allow multiple application servers to share cached data.
- Caching is most effective for read-heavy workloads with repetitive access patterns.
- Caches improve performance but introduce consistency and invalidation challenges.
