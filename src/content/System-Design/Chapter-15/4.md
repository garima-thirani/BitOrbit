# Interview Questions & Solutions

## Question 1

### Question

Why is LRU the most widely used cache eviction policy?

### Ideal Answer

LRU is based on temporal locality—the assumption that recently accessed data is likely to be accessed again soon. This makes it highly effective for web applications with repetitive access patterns.

---

## Question 2

### Question

When is LFU preferable to LRU?

### Ideal Answer

LFU is better when long-term popularity matters more than recent activity, such as caching frequently accessed reference data or analytics dashboards where access frequency is a stronger predictor than recency.

---

## Question 3

### Question

Why doesn't Memcached support persistence?

### Ideal Answer

Memcached is designed solely as a high-performance cache. By avoiding persistence, replication, and advanced features, it minimizes overhead and maximizes throughput and simplicity.

---

## Question 4

### Question

What is memory fragmentation?

### Ideal Answer

Memory fragmentation occurs when repeated allocation and deallocation create scattered free memory blocks, reducing memory efficiency and potentially preventing large allocations despite sufficient total free memory.

---

## Question 5 (FAANG)

### Question

Design the cache eviction strategy for a global video streaming platform.

### Ideal Answer

Use LRU combined with TTL for movie metadata and recommendations, LFU for long-lived popular titles, short TTLs for rapidly changing data, cache warmup after deployments, continuous monitoring of hit ratios and evictions, and active defragmentation to maintain efficient memory usage. Tune eviction policies based on observed production access patterns rather than fixed assumptions.

# Revision Notes

- Memcached is a lightweight, in-memory key-value cache focused on simplicity and speed.
- Redis offers richer functionality, including persistence, replication, clustering, and advanced data structures.
- Cache eviction policies determine which objects are removed when memory is full.
- LRU favors recently accessed objects, while LFU favors frequently accessed objects.
- TTL automatically removes stale cache entries after a specified duration.
- Memory fragmentation reduces effective memory utilization and should be monitored.
- Cache warmup minimizes cold-start effects after restarts or deployments.
