# Introduction

Netflix's biggest competitive advantage isn't streaming.

It's helping users discover content they'll actually watch.

Consider two users.

Alice loves:

- Science Fiction
- Space Movies
- Christopher Nolan

Bob prefers:

- Comedy
- Sitcoms
- Family Movies

When they open Netflix,

they should **not** see the same home page.

Instead,

Netflix generates a personalized experience for every user.

---

# Why Recommendations Matter

Netflix contains

```
100,000+
Movies & Shows
```

Without recommendations,

users would spend more time searching than watching.

Netflix's goal is simple:

> **Help users find something to watch within a few minutes.**

# Kafka Event Pipeline

Every interaction becomes an event.

```text
User Action

↓

Kafka

↓

Consumers
```

Consumers include:

- Watch History
- Recommendations
- Analytics
- Trending
- ML Training

---

# Why Kafka?

Without Kafka,

every click would synchronously update multiple services.

Instead,

Netflix publishes one event.

```text
Play Movie

↓

Kafka

↓

Recommendation

Analytics

History

ML
```

Loose coupling makes the system scalable.

# Collaborative Filtering

Core idea:

> Users with similar tastes probably enjoy similar movies.

Example:

```text
Alice likes:

Interstellar

Inception

Arrival
```

Bob likes:

```text
Interstellar

Arrival
```

Recommend

```
Inception
```

to Bob.

---

# Content-Based Filtering

Instead of comparing users,

compare movies.

Example:

```text
Interstellar

↓

Science Fiction

Space

Christopher Nolan
```

Recommend similar movies.

---

# Popularity-Based Recommendations

# Key Takeaways

- Netflix recommendations combine collaborative filtering, content-based filtering, popularity, and machine learning.
- Every user interaction generates Kafka events that continuously improve personalization.
- Watch History and Continue Watching are lightweight metadata services independent of video streaming.
- Search relies on dedicated search indexes rather than scanning databases.
- Personalized home pages are dynamically generated using ML ranking models.
- Analytics and A/B testing continuously optimize the user experience.
- Recommendation systems are among Netflix's most valuable competitive advantages.
- The next step is designing Netflix's globally distributed production infrastructure.
