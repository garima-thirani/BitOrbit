📖 The Story — Pizza Shop
Efficient Waiting

One pizza takes 10 minutes. Three customers waiting sequentially takes 30 minutes. Starting all pizzas together and waiting simultaneously takes ~10 minutes. This is async programming.

Imagine a pizza shop where one pizza takes 10 minutes. Three customers arrive. In synchronous execution, each pizza is made sequentially: 10 + 10 + 10 = 30 minutes. In asynchronous execution, all three pizzas start simultaneously and finish together in about 10 minutes. Asynchronous programming works the same way. Instead of waiting idly, your program performs other useful work while waiting for IO operations to complete.

🔧 Basic Asyncio Example
Your first async program:

import asyncio

# Define a coroutine
async def greet(name):
  print(f"Hello {name}")
  await asyncio.sleep(1) # Non-blocking sleep
  print(f"Goodbye {name}")

# Run the coroutine
async def main():
  await greet("Alice")
  await greet("Bob")

asyncio.run(main())
🔧 Multiple Coroutines Example
Running multiple coroutines concurrently:

import asyncio

async def task(name, delay):
  print(f"{name} started")
  await asyncio.sleep(delay)
  print(f"{name} finished")
  return f"Result from {name}"

async def main():
  # Run tasks concurrently
  results = await asyncio.gather(
    task("A", 2),
    task("B", 1),
    task("C", 3)
  )
  print(results)

asyncio.run(main())
# Total time: ~3 seconds (not 6)
🔧 Async with Example
Async context manager:

import asyncio

class AsyncDatabase:
  async def __aenter__(self):
    print("Connecting to database")
    await asyncio.sleep(0.5)
    return self

  async def __aexit__(self, exc_type, exc_val, exc_tb):
    print("Closing connection")
    await asyncio.sleep(0.5)

  async def query(self):
    print("Executing query")
    await asyncio.sleep(1)

async def main():
  async with AsyncDatabase() as db:
    await db.query()

asyncio.run(main())
⚠️ Common Mistakes
❌
Using time.sleep() in async code.
✔ Use await asyncio.sleep(). time.sleep() blocks the event loop.
❌
Forgetting to await async functions.
✔ Always use await when calling async functions. Missing await returns a coroutine object without executing it.
❌
Using asyncio for CPU-intensive tasks.
✔ Asyncio is for IO-bound tasks. For CPU-bound work, use multiprocessing.
❌
Thinking asyncio creates multiple threads.
✔ Asyncio runs in a single thread. Concurrency comes from cooperative multitasking, not parallelism.
🎯 Interview Questions
Q
"What is asyncio and when would you use it?"
"Asyncio is Python's framework for asynchronous programming. It uses an event loop to manage coroutines, allowing many IO-bound operations to run concurrently in a single thread. Use it for network servers, APIs, web scrapers, or any application with many concurrent IO operations. It's more efficient than threading for thousands of connections."
Q
"What is the difference between threading and asyncio?"
"Threading uses OS scheduler to switch between threads, limited by GIL for CPU-bound tasks. Asyncio uses cooperative multitasking in a single thread with an event loop. Asyncio has less overhead than threads, making it better for thousands of concurrent IO operations. Threads are better when you need to run blocking code."
