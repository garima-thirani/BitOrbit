📖 The Story — Family Tree
Traits & Behaviors

Children inherit traits from parents but also have their own unique characteristics. This is inheritance in OOP.

Imagine a family tree. Children inherit traits from their parents (eye color, height) but also have their own unique characteristics. In OOP, inheritance works the same way. A child class (subclass) inherits attributes and methods from a parent class (superclass) but can also add its own unique features or override inherited behaviors.

🔧 Inheritance Example
Single Inheritance:

class Animal:
  def __init__(self, name):
    self.name = name

  def speak(self):
    return "Some sound"

class Dog(Animal): # Inherits from Animal
  def speak(self): # Override
    return f"{self.name} says woof!"

dog = Dog("Buddy")
print(dog.speak()) # "Buddy says woof!"
⚠️ Common Mistakes
❌
Overusing inheritance.
✔ Prefer composition over inheritance. Inheritance creates tight coupling. Use inheritance when there's a clear "is-a" relationship.
❌
Forgetting to call super().__init__().
✔ When overriding __init__, call super().__init__() to initialize the parent class.
❌
Using private attributes incorrectly.
✔ Python doesn't have true private attributes. Use single underscore (_) for "protected" and double underscore (__) for name mangling.
🎯 Interview Questions
Q
"What is inheritance?"
"Inheritance allows a class to inherit attributes and methods from another class. The child class reuses code from the parent class and can add new features or override existing ones. It promotes code reusability and follows the DRY principle."
Q
"What is polymorphism?"
"Polymorphism allows different classes to have methods with the same name but different implementations. For example, Dog and Cat both have a speak() method, but each implements it differently. This enables writing generic code that works with multiple types."
Q
"What is encapsulation?"
"Encapsulation is the practice of hiding internal state and requiring all interaction through methods. It protects data from direct modification. In Python, we use _ for protected and __ for private attributes (name mangling)."
