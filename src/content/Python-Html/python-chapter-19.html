📖 The Story — Library Books
Organized Knowledge

A library organizes books by subject. You can borrow specific books without carrying the entire library.

Imagine a library. Books are organized into sections (Mathematics, Physics, History). Instead of carrying the entire library, you borrow only the books you need. Python modules work exactly like this. A module is a single Python file containing related code. A package is a folder containing multiple modules. You import only what you need.

🔧 Module Example
Creating a module (utils.py):

def greet(name):
  return f"Hello, {name}!"

def add(a, b):
  return a + b

Using the module (main.py):

import utils
print(utils.greet("Alice")) # "Hello, Alice!"
print(utils.add(5, 3)) # 8
⚠️ Common Mistakes
❌
Circular imports.
✔ Avoid circular imports where module A imports B and B imports A. Restructure code to prevent this.
❌
Using from module import *.
✔ This pollutes the namespace and makes it unclear where functions come from. Import specific items or use the module prefix.
❌
Placing import statements inside functions unnecessarily.
✔ Keep imports at the top of the file (PEP 8). Only use local imports when there's a specific reason (e.g., avoiding circular imports).
🎯 Interview Questions
Q
"What is a Python module?"
"A module is a Python file containing related functions, classes, and variables. It allows code reuse and organization. Python's standard library has many built-in modules like math, random, and datetime."
Q
"What is the difference between a module and a package?"
"A module is a single .py file. A package is a directory containing multiple modules and an __init__.py file. Packages allow hierarchical organization of related modules."
