🔧 Vectorization Example
Vectorization vs loops:

import numpy as np
import time

arr = np.arange(1000000)

# Slow: Python loop
start = time.time()
result = []
for x in arr:
  result.append(x * 2)
print(f"Loop: {time.time() - start:.4f}s")

# Fast: Vectorized
start = time.time()
result = arr * 2
print(f"Vectorized: {time.time() - start:.4f}s")

# Vectorized is 50-100x faster!
🔧 In-place Operations Example
Memory-efficient in-place operations:

import numpy as np

arr = np.array([1, 2, 3, 4, 5])

# Creates new array (wastes memory)
arr = arr + 5

# Modifies in-place (efficient)
arr += 5  # Same as arr = arr + 5 but no copy
arr *= 2
arr -= 1

# In-place operations:
# +=, -=, *=, /=, //=, %=
🔧 Memory-Efficient Data Types Example
Choosing the right dtype:

import numpy as np

# Default int64 (8 bytes each)
arr1 = np.array([1, 2, 3], dtype=np.int64)
print(arr1.itemsize)  # 8 bytes

# int32 (4 bytes each) - 50% memory savings
arr2 = np.array([1, 2, 3], dtype=np.int32)
print(arr2.itemsize)  # 4 bytes

# uint8 (1 byte) for 0-255 values
arr3 = np.array([100, 150, 200], dtype=np.uint8)
print(arr3.itemsize)  # 1 byte - 87.5% savings!

# Common dtypes:
# int8/16/32/64, uint8/16/32/64
# float32/64, bool
🔧 Profiling Example
Measuring performance:

import numpy as np
import timeit

# Time different approaches
loop_time = timeit.timeit(
  'result = [x*2 for x in range(1000)]',
  number=1000
)

numpy_time = timeit.timeit(
  'arr = np.arange(1000); result = arr * 2',
  setup='import numpy as np',
  number=1000
)

print(f"Loop: {loop_time:.4f}s")
print(f"NumPy: {numpy_time:.4f}s")
print(f"Speedup: {loop_time/numpy_time:.1f}x")
⚠️ Common Mistakes
❌
Using Python loops with NumPy arrays.
✔ Always use vectorized operations. They're 10-100x faster than loops.
❌
Creating unnecessary copies.
✔ Use views when possible. Use in-place operations to save memory.
❌
Using default int64/float64 everywhere.
✔ Choose smallest dtype that fits your data. Saves memory and improves cache efficiency.
❌
Optimizing without profiling.
✔ Measure first with timeit or profiler. Optimize actual bottlenecks, not guessed ones.
🎯 Interview Questions
Q
"Why is NumPy faster than Python lists?"
"NumPy is faster because: 1) Contiguous memory layout - better CPU cache utilization, 2) Optimized C implementation - no Python interpreter overhead, 3) Vectorization - operations on entire arrays at once, 4) SIMD instructions - CPU-level parallelism, 5) Specialized algorithms - optimized for numerical operations. Python lists store references to scattered objects with type checking overhead."
Q
"How do you optimize NumPy code?"
"I follow these principles: 1) Vectorize everything - avoid Python loops, use ufuncs, 2) Use broadcasting instead of manual tiling, 3) Choose appropriate dtypes to save memory, 4) Use in-place operations when possible, 5) Prefer views over copies, 6) Profile with timeit before optimizing. The biggest gains come from eliminating loops and using vectorized operations."
