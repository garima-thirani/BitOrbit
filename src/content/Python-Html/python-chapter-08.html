📖 The Story — Pizza Restaurant
Order and Execute

Customers order pizza without knowing how it's made. The kitchen handles the details. Functions work the same way.

Imagine a pizza restaurant. Customers order different pizzas. The customer doesn't care how the pizza is made—they only need to place an order. Functions work exactly like this. The caller doesn't need to know the internal implementation. A function is simply a named block of code that performs a specific task. Instead of writing the same code again and again, you write it once, give it a name, and reuse it whenever needed.

🔄 Function Lifecycle
📝 Function Syntax
Every function has four parts:

def function_name(parameters): ← Definition
    """Docstring""" ← Documentation
    # Function Body ← Logic
    return value ← Return (optional)

Example:
def square(number):
    """Returns the square of a number."""
    return number * number

result = square(5) # result = 25
📊 print() vs return
Aspectprint()return
PurposeDisplay output on screenSend value back to caller
ReusabilityCannot reuse the outputCan store and reuse the value
Exampleprint(a + b)return a + b
UsageDebugging, user messagesReal programs, calculations
Bad: def add(a, b): print(a + b) — can't use the result
Good: def add(a, b): return a + b — result can be stored: result = add(5, 8)
🎯 Variable Scope
Local variables are created inside a function and cannot be accessed outside it.
Global variables are defined outside every function and are accessible everywhere.

Example:
x = 100 # Global
def demo():
  x = 50 # Local (shadows global)
  print(x) # 50
demo()
print(x) # 100 (global unchanged)
⚠️ Common Beginner Mistakes
❌
Defining a function but forgetting to call it.
✔ Defining a function does NOT execute it. You must call it: greet(). Nothing happens until you make the function call.
❌
Confusing parameters and arguments.
✔ Parameters are variables in the function definition (def greet(name):). Arguments are the actual values passed (greet("Alice")).
❌
Using print() instead of return.
✔ Use return when another part of the program needs the result. Use print() only for displaying output.
❌
Trying to access local variables outside the function.
✔ Variables created inside a function only exist while the function is running. They are destroyed when the function returns.
🎯 Interview Questions
Q
"What is a function and why are functions important?"
"A function is a reusable block of code that performs a specific task. Functions are important because they reduce code duplication, improve readability, simplify testing, improve maintainability, and encourage modular design. They are one of the fundamental building blocks of software engineering."
Q
"What is the difference between a parameter and an argument?"
"A parameter is a variable in the function definition that receives a value. An argument is the actual value passed to the function when it is called. For example, in def greet(name):, name is a parameter. In greet('Alice'), 'Alice' is an argument."
Q
"What is the difference between print() and return?"
"print() displays a value on the screen but does not make it available for further use. return sends a value back to the caller, allowing it to be stored, used in calculations, or passed to other functions. Always prefer return when the result needs to be reused."
Q
"What is variable scope?"
"Scope defines where a variable is accessible in a program. Python has local scope (variables created inside a function) and global scope (variables defined outside all functions). Local variables cannot be accessed outside their function, which helps prevent naming conflicts and unintended modifications."
