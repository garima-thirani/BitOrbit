📖 The Story — Photocopy
Copying Books

You can share a book, photocopy just the cover, or photocopy the entire book. Python copying works the same way - assignment, shallow copy, and deep copy.

Imagine you have a book. You have three options: 1) Let a friend borrow the same book (assignment), 2) Photocopy only the cover (shallow copy), or 3) Photocopy the entire book (deep copy). Python objects work similarly. Assignment creates another reference to the same object. Shallow copy creates a new outer object but shares nested objects. Deep copy duplicates everything recursively.

🔧 Assignment vs Copy Example
Understanding the differences:

import copy

# Assignment - same object
list1 = [1, 2, 3]
list2 = list1 # Same reference
list2.append(4)
print(list1) # [1, 2, 3, 4] - changed!

# Shallow Copy - new outer, shared inner
list3 = [1, 2, [3, 4]]
list4 = copy.copy(list3)
list4[2].append(5) # Modifies shared inner
print(list3) # [1, 2, [3, 4, 5]] - changed!

# Deep Copy - everything independent
list5 = [1, 2, [3, 4]]
list6 = copy.deepcopy(list5)
list6[2].append(5) # Only changes list6
print(list5) # [1, 2, [3, 4]] - unchanged!
🔧 Memory Profiling Example
Measuring memory usage:

import sys
import tracemalloc

# Get size of single object
list1 = [1, 2, 3, 4, 5]
print(sys.getsizeof(list1)) # bytes

# Track memory allocations
tracemalloc.start()

# Your code here
data = [i for i in range(10000)]

# Get memory stats
snapshot = tracemalloc.take_snapshot()
for stat in snapshot.statistics('lineno')[:5]:
  print(stat)

tracemalloc.stop()
🔧 Memory-Efficient Patterns
Writing memory-efficient code:

# Use generators instead of lists
# Bad: Creates entire list in memory
squares = [x*x for x in range(1000000)]

# Good: Generates one at a time
squares = (x*x for x in range(1000000))

# Use __slots__ for classes
class Point:
  __slots__ = ['x', 'y'] # No __dict__
  def __init__(self, x, y):
    self.x = x
    self.y = y

# Saves memory when creating many objects
⚠️ Common Mistakes
❌
Using deep copy when shallow copy suffices.
✔ Deep copy is slower and uses more memory. Use it only when you need complete independence.
❌
Not profiling before optimizing.
✔ Measure memory usage first with tracemalloc or memory_profiler. Optimize based on data, not guesses.
❌
Creating large intermediate lists.
✔ Use generators or iterators for large datasets. They produce values on-demand, saving memory.
❌
Ignoring object overhead.
✔ Small objects add up. Use __slots__ for classes with many instances. Choose appropriate data structures.
🎯 Interview Questions
Q
"What's the difference between shallow copy and deep copy?"
"Shallow copy creates a new outer object but shares references to nested objects with the original. Deep copy creates a completely independent copy of the entire object graph. Modifying nested objects in a shallow copy affects the original, but deep copy is fully independent. Use copy.copy() for shallow, copy.deepcopy() for deep."
Q
"How do you profile memory usage in Python?"
"Python offers several tools: sys.getsizeof() for individual objects, tracemalloc (built-in) for tracking allocations over time, and memory_profiler for line-by-line analysis. For production, use objgraph to find object leaks. Always profile before optimizing to identify actual bottlenecks."
