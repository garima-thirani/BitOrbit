📖 The Story — Expert Committee
Collective Intelligence

A single expert might make mistakes. A committee of experts voting together usually makes better decisions. Ensemble methods work the same way.

Imagine a medical diagnosis. One doctor might misdiagnose a rare condition. But if ten experienced doctors vote, the collective decision is usually more accurate. Ensemble methods in ML work exactly like this. Random Forest creates multiple decision trees and combines their predictions. Gradient Boosting builds trees sequentially, each correcting the previous one's mistakes. This "wisdom of crowds" approach often produces the best results in ML competitions.

🔧 Random Forest Example
Using ensemble methods:

from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# Create model with 100 trees
model = RandomForestClassifier(
  n_estimators=100,
  max_depth=10,
  random_state=42
)

# Train
model.fit(X_train, y_train)

# Predict
y_pred = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.2f}")

# Feature importance
print(model.feature_importances_)
🔧 SVM Example
Support Vector Machine:

from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler

# SVM requires scaled features
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)

# Create SVM with RBF kernel
model = SVC(kernel='rbf', C=1.0, gamma='auto')

# Train and predict
model.fit(X_train_scaled, y_train)
accuracy = model.score(X_test, y_test)
print(f"Accuracy: {accuracy:.2f}")
⚠️ Common Mistakes
❌
Not tuning hyperparameters.
✔ Use GridSearchCV or RandomizedSearchCV to find optimal parameters. Default parameters are rarely best.
❌
Ignoring overfitting.
✔ If training accuracy is much higher than test accuracy, your model is overfitting. Use regularization, pruning, or more data.
❌
Using complex models when simple ones work.
✔ Start with simple models (logistic regression, decision tree). Only use complex models when needed.
🎯 Interview Questions
Q
"What is ensemble learning and why does it work?"
"Ensemble learning combines multiple models to improve performance. It works because different models make different errors - when combined, errors cancel out. Two main types: Bagging (train models in parallel, e.g., Random Forest) and Boosting (train sequentially, each correcting previous errors, e.g., XGBoost). Ensembles often win ML competitions."
Q
"What is the difference between Random Forest and Gradient Boosting?"
"Random Forest uses bagging: multiple trees trained in parallel on different data subsets, then voting. Gradient Boosting uses boosting: trees trained sequentially, each focusing on previous errors. Random Forest is faster to train, more resistant to overfitting. Gradient Boosting often achieves higher accuracy but needs careful tuning."
