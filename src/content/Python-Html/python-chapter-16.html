📖 The Story — Insurance Policy
Protection & Recovery

An insurance policy protects you when something goes wrong. Exception handling is your program's insurance policy.

Imagine you're driving a car. You have insurance in case of accidents, a spare tire for flat tires, and a first-aid kit for emergencies. Exception handling works the same way. The try block is your normal driving. The except blocks are your insurance policies for different problems. The finally block is like locking your car—it always happens, regardless of what went wrong.

🔧 Exception Handling Example
Basic structure:

try:
  # Risky code
  result = 10 / int(input("Enter number: "))

except ValueError:
  print("Please enter a valid number")

except ZeroDivisionError:
  print("Cannot divide by zero")

else:
  print(f"Result: {result}")

finally:
  print("Cleanup code here")
⚠️ Common Mistakes
❌
Catching exceptions too broadly.
✔ Catch specific exceptions. Avoid bare except: which catches everything including SystemExit and KeyboardInterrupt.
❌
Using exceptions for control flow.
✔ Exceptions are for exceptional cases, not normal program flow. Use if-else for expected conditions.
❌
Swallowing exceptions silently.
✔ Always log or handle exceptions properly. Empty except blocks make debugging impossible.
🎯 Interview Questions
Q
"What is exception handling?"
"Exception handling is a mechanism to handle runtime errors gracefully. It uses try-except blocks to catch and handle exceptions, preventing the program from crashing. The finally block ensures cleanup code always runs."
Q
"What is the difference between except and finally?"
"except catches and handles exceptions. finally always executes, whether an exception occurred or not. finally is used for cleanup code like closing files or database connections."
