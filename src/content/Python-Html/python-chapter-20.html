📖 The Story — Notebook
Persistent Storage

A notebook stores information that persists even after you close it. Files work the same way for programs.

Imagine a notebook where you write notes. The information stays there even after you close the notebook. Later, you can open it and read what you wrote. Computer files work exactly like this. They provide persistent storage — data that survives after your program ends. You can read from files, write to files, and the with statement ensures the file is properly closed (like closing your notebook).

🔧 File I/O Example
Using with statement (recommended):

# Write to file
with open("notes.txt", "w") as file:
  file.write("Hello, World!\n")
  file.write("Python is awesome\n")

# Read from file
with open("notes.txt", "r") as file:
  content = file.read()
  print(content)

Benefits: Automatically closes file, even if error occurs.
⚠️ Common Mistakes
❌
Forgetting to close files.
✔ Always use with statement. It automatically closes the file. If not using with, call file.close() explicitly.
❌
Using write mode ('w') when you mean append.
✔ 'w' overwrites the entire file. 'a' appends to the end. Be careful with 'w' — you can lose data!
❌
Not handling file not found errors.
✔ Use try-except or check if file exists before opening. FileNotFoundError is common.
🎯 Interview Questions
Q
"What is the with statement and why is it used?"
"The with statement is a context manager that automatically handles resource cleanup. For files, it ensures the file is properly closed after operations, even if an exception occurs. It's the recommended way to work with files in Python."
Q
"What's the difference between 'w' and 'a' modes?"
"'w' (write) mode overwrites the entire file, creating a new file if it doesn't exist. 'a' (append) mode adds content to the end of the file without removing existing content. Use 'w' for new files and 'a' for logging or adding to existing files."
