📖 The Story — Factory Robot
Repetition Automation

Instead of giving a robot individual instructions for every box, we simply tell it: "Repeat 1000 times."

Imagine a factory robot assigned to pack boxes. Without loops, the robot would need individual instructions for every box: "Pack Box 1, Pack Box 2, Pack Box 3..." up to 1000. Instead, we simply tell it: "Repeat 1000 times." That's exactly what loops do. A loop repeatedly executes a block of code until a condition becomes false or all items have been processed.

🔄 The for Loop
for loop is used to iterate over a sequence (list, string, tuple, dictionary, set, file).

Syntax: for variable in iterable: statement

Example:
fruits = ["Apple", "Banana", "Mango"]
for fruit in fruits:
  print(fruit)

Why prefer for over while? Cleaner, shorter, less error-prone. No need to manage index variables manually.

🔄 enumerate() & zip()

enumerate() — Index + Value

names = ["Alice", "Bob", "Charlie"] # Instead of: for i in range(len(names)): print(i, names[i]) # Pythonic way: for index, name in enumerate(names): print(index, name) # Output: 0 Alice, 1 Bob, 2 Charlie

zip() — Combine Iterables

names = ["Alice", "Bob"] marks = [90, 85] # Instead of: for i in range(len(names)): print(names[i], marks[i]) # Pythonic way: for name, mark in zip(names, marks): print(name, mark) # Output: Alice 90, Bob 85
🔄 Nested Loops
Nested loops are loops inside other loops. The inner loop completes all its iterations for each iteration of the outer loop.

Example — Multiplication Table:
for i in range(1, 4):
  for j in range(1, 6):
    print(i * j, end=" ")
  print()

Output:
1 2 3 4 5
2 4 6 8 10
3 6 9 12 15
⚠️ Common Beginner Mistakes
❌
Creating an infinite loop (forgetting to update the counter).
✔ Always ensure the loop condition will eventually become False. In while loops, remember to increment your counter: count += 1.
❌
Using range(len(list)) when for item in list is sufficient.
✔ If you only need the values, iterate directly. Use enumerate() only when you also need the index.
❌
Forgetting that range(5) starts at 0, not 1.
✔ range(5) produces 0, 1, 2, 3, 4. Use range(1, 6) for 1 through 5.
❌
Using indexes when enumerate() or zip() would be clearer.
✔ Pythonic code prefers enumerate() for index+value and zip() for combining lists.
🎯 Interview Questions
Q
"What is the difference between for and while?"
"A while loop continues as long as a condition is true. A for loop iterates over a sequence or iterable. Use while when the number of iterations is unknown (e.g., waiting for user input). Use for when iterating over a collection (e.g., processing each item in a list)."
Q
"Why is enumerate() better than range(len())?"
"enumerate() directly returns both the index and the value, making code simpler and more readable. It's more Pythonic and less error-prone than manually managing indices with range(len())."
Q
"What is the difference between range(5) and range(1, 6)?"
"range(5) produces 0, 1, 2, 3, 4 (starts at 0, stops before 5). range(1, 6) produces 1, 2, 3, 4, 5 (starts at 1, stops before 6). The stop value is always exclusive."
