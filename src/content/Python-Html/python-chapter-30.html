Scientific Computing

A laboratory has specialized tools for different experiments. Data science has specialized libraries for different tasks.

Imagine a scientific laboratory. For precise measurements, scientists use calibrated instruments (NumPy). For organizing and analyzing experimental data, they use spreadsheets and databases (Pandas). For visualizing results, they use graphs and charts (Matplotlib). Python's data science ecosystem works the same way. NumPy provides fast numerical arrays. Pandas offers powerful data structures for analysis. Together, they form the foundation of Python data science.

🔧 NumPy Example
Working with NumPy arrays:

import numpy as np

# Create array
arr = np.array([1, 2, 3, 4, 5])
matrix = np.array([[1, 2], [3, 4]])

# Operations (vectorized)
print(arr * 2) # [2 4 6 8 10]
print(arr + 10) # [11 12 13 14 15]
print(np.sqrt(arr)) # [1. 1.41 1.73 2. 2.24]

# Statistics
print(arr.mean()) # 3.0
print(arr.max()) # 5
print(arr.std()) # 1.41
🔧 Pandas Example
Working with DataFrames:

import pandas as pd

# Create DataFrame
df = pd.DataFrame({
  "name": ["Alice", "Bob", "Charlie"],
  "age": [25, 30, 35],
  "city": ["NYC", "LA", "Chicago"]
})

# Load from CSV
df = pd.read_csv("data.csv")

# Explore
print(df.head()) # First 5 rows
print(df.describe()) # Statistics
print(df.info()) # Data types

# Filter
filtered = df[df["age"] > 25]
result = df.query("city == 'NYC'")
⚠️ Common Mistakes
❌
Using Python loops instead of vectorized operations.
✔ NumPy and Pandas are optimized for vectorized operations. Avoid iterating over rows - use built-in functions instead.
❌
Not handling missing data.
✔ Use df.isnull().sum() to check for missing values. Handle with df.dropna() or df.fillna().
❌
Modifying data without copying.
✔ Use df.copy() when you need to modify a DataFrame without changing the original.
🎯 Interview Questions
Q
"What's the difference between NumPy arrays and Python lists?"
"NumPy arrays are more efficient than Python lists for numerical operations. They store data in contiguous memory, support vectorized operations (no loops needed), and provide mathematical functions. Lists are more flexible (can store different types) but slower for numerical computing. Use NumPy for data analysis, lists for general purposes."
Q
"What is a Pandas DataFrame?"
"A DataFrame is a 2D labeled data structure with columns of potentially different types. Think of it as a spreadsheet or SQL table. It has rows and columns, each with an index. DataFrames provide powerful data manipulation: filtering, grouping, merging, aggregation. They're the core data structure for data analysis in Python."
