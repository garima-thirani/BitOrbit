📖 The Story — ATM Machine
Decision Flow

An ATM doesn't immediately give you cash. It asks questions and makes decisions at every step.

Imagine withdrawing money from an ATM. The ATM doesn't immediately give you cash. Instead, it asks: Is the card valid? Is the PIN correct? Is there enough balance? If any answer is No, the process stops. Python's decision-making works exactly like this. Every decision is based on a Boolean expression that evaluates to True or False.

🔄 match-case Statement (Python 3.10+)
match-case is Python's pattern matching statement, introduced in Python 3.10. It provides a cleaner alternative to long if-elif chains when matching fixed values.

Syntax:
match value:
  case 1: print("Monday")
  case 2: print("Tuesday")
  case _: print("Invalid") ← _ is the default case

Best for: Menus, Commands, State Machines, Fixed Choices
🔀 Ternary Operator (Conditional Expression)
Ternary operator allows writing a simple if-else in one line.

Instead of:
if age >= 18:
  status = "Adult"
else:
  status = "Minor"

Write:
status = "Adult" if age >= 18 else "Minor"

Use only when it improves readability. For complex conditions, stick with regular if-else.
⚠️ Common Beginner Mistakes
❌
Using = instead of == in conditions.
✔ if age = 18: is incorrect. Use if age == 18: for comparison. = is for assignment, == is for comparison.
❌
Incorrect indentation after if.
✔ Python requires indentation after every if, elif, and else. Use 4 spaces consistently.
❌
Using separate if statements when elif is appropriate.
✔ Multiple if statements check every condition. elif stops checking after one condition is True.
❌
Writing deeply nested if statements.
✔ Combine conditions using and or or when appropriate. Deep nesting makes code hard to read.
🎯 Interview Questions
Q
"What is the difference between if and if-else?"
"An if statement executes a block only when the condition is true. An if-else statement always executes exactly one block—the if block when true, the else block when false. Use if when no action is needed for the false case, and if-else when both outcomes require different actions."
Q
"What is the difference between if-elif-else and nested if?"
"if-elif-else is used for checking multiple mutually exclusive conditions. Nested if is used when one condition depends on another. For example, checking if a user is eligible to vote requires first checking age, then citizenship—this is a nested if scenario."
Q
"What is the ternary operator in Python?"
"The ternary operator is a one-line conditional expression: value_if_true if condition else value_if_false. It should be used only for simple conditions where it improves readability. For complex logic, regular if-else is preferred."
