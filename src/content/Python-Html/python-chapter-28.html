📖 The Story — Gift Wrapping
Enhancement

A gift box enhances the gift inside. Decorators enhance functions without changing them.

Imagine wrapping a gift. The wrapping paper doesn't change the gift - it enhances it, adds presentation, and protects it. You can wrap any gift with the same paper. Python decorators work exactly like this. A decorator is a function that wraps another function, adding functionality without modifying the original function. Context managers are like gift boxes - they ensure proper setup and cleanup. Metaclasses are like the mold that shapes the gift box itself.

🔧 Decorator Example
Creating a decorator:

# Decorator function
def timer(func):
  def wrapper(*args, **kwargs):
    import time
    start = time.time()
    result = func(*args, **kwargs)
    end = time.time()
    print(f"{func.__name__} took {end-start:.2f}s")
    return result
  return wrapper

# Using decorator
@timer
def slow_function():
  import time
  time.sleep(1)

slow_function() # "slow_function took 1.00s"
🔧 Context Manager Example
Creating a context manager:

from contextlib import contextmanager

@contextmanager
def timer_context():
  import time
  start = time.time()
  yield # Code runs here
  end = time.time()
  print(f"Elapsed: {end-start:.2f}s")

# Using context manager
with timer_context():
  # Your code here
  import time
  time.sleep(1)
# "Elapsed: 1.00s"
⚠️ Common Mistakes
❌
Forgetting to use @functools.wraps in decorators.
✔ Always use @wraps(func) to preserve function metadata (name, docstring). Otherwise, your decorated function loses its identity.
❌
Overusing decorators.
✔ Decorators are powerful but can make code hard to debug. Use them for cross-cutting concerns (logging, timing, auth), not business logic.
❌
Using metaclasses when simpler solutions exist.
✔ Metaclasses are complex. Consider class decorators or __init_subclass__ before using metaclasses.
🎯 Interview Questions
Q
"What is a decorator and when would you use one?"
"A decorator is a function that wraps another function to add functionality without modifying it. Use decorators for cross-cutting concerns like logging, timing, authentication, caching, or validation. They promote code reuse and separation of concerns. Example: @app.route in Flask, @property in classes."
Q
"What is a context manager?"
"A context manager is an object that defines __enter__ and __exit__ methods, used with the with statement. It ensures proper resource management - setup happens in __enter__, cleanup in __exit__. Common examples: file handling (auto-close), database connections, locks. The with statement guarantees cleanup even if exceptions occur."
