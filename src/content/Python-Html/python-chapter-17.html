📖 The Story — House Blueprint
Template & Instances

A blueprint defines how to build houses. Each house built from that blueprint is a unique instance with its own properties.

Imagine an architect creates a blueprint for a house. The blueprint defines the structure: number of rooms, dimensions, materials. From this single blueprint, you can build many houses. Each house is unique (different address, different paint color) but follows the same design. OOP works exactly like this. A class is the blueprint. An object (instance) is the actual house built from that blueprint.

🔧 Basic Class Example
Creating a simple class:

class Dog:
  # Constructor
  def __init__(self, name, breed):
    self.name = name
    self.breed = breed

  # Method
  def bark(self):
    return f"{self.name} says woof!"

# Create object
dog1 = Dog("Buddy", "Golden Retriever")
print(dog1.bark()) # "Buddy says woof!"
⚠️ Common Mistakes
❌
Forgetting self parameter in methods.
✔ Every instance method must have self as the first parameter. Python passes the current object automatically.
❌
Confusing class variables with instance variables.
✔ Class variables are shared by all instances. Instance variables are unique to each object. Use self.variable for instance variables.
❌
Trying to access instance variables from the class itself.
✔ Instance variables only exist after creating an object. Access them via objects: dog1.name, not Dog.name.
🎯 Interview Questions
Q
"What is OOP?"
"OOP (Object-Oriented Programming) is a programming paradigm that organizes code around objects. Objects combine data (attributes) and behavior (methods). It promotes code reusability, modularity, and maintainability through concepts like classes, inheritance, and encapsulation."
Q
"What is the difference between a class and an object?"
"A class is a blueprint or template that defines the structure and behavior of objects. An object is an instance of a class—a concrete entity created from that blueprint. For example, 'Car' is a class, while 'my_car' is an object."
Q
"What is self in Python?"
"self is a reference to the current instance of the class. It's the first parameter of every instance method. Python automatically passes the current object as the first argument when you call a method on an object."
