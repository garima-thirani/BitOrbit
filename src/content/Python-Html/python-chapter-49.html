Efficient Storage

A warehouse with neatly organized shelves is faster to navigate than scattered boxes. NumPy organizes data like a warehouse - structured, fast, and efficient.

Imagine two warehouses. Warehouse A has boxes scattered randomly everywhere. Finding a specific box takes forever. Warehouse B has boxes neatly arranged on labeled shelves in rows and columns. Finding any box is instant. NumPy arrays are like Warehouse B. 🔧 Creating Arrays Example
Different ways to create NumPy arrays:

import numpy as np

# From list
arr1 = np.array([1, 2, 3, 4, 5])

# 2D array
arr2 = np.array([[1, 2, 3], [4, 5, 6]])

# Special arrays
zeros = np.zeros((3, 3)) # 3x3 zeros
ones = np.ones((2, 4))   # 2x4 ones
eye = np.eye(3)         # Identity matrix
arange = np.arange(0, 10, 2)  # [0, 2, 4, 6, 8]
linspace = np.linspace(0, 1, 5) # 5 evenly spaced
random = np.random.rand(3, 3)  # Random 3x3
🔧 Array Attributes Example
Understanding array properties:

import numpy as np

arr = np.array([[1, 2, 3], [4, 5, 6]])

# Array attributes
print(arr.shape)   # (2, 3) - 2 rows, 3 cols
print(arr.ndim)    # 2 - 2 dimensions
print(arr.size)    # 6 - total elements
print(arr.dtype)   # int64 - data type
🔧 Lists vs NumPy Arrays
Why NumPy is faster:

import numpy as np
import time

# Python list
list1 = list(range(1000000))
list2 = list(range(1000000))

# NumPy arrays
arr1 = np.arange(1000000)
arr2 = np.arange(1000000)

# List multiplication (slow)
start = time.time()
result_list = [a * b for a, b in zip(list1, list2)]
print(f"List: {time.time() - start:.4f}s")

# NumPy multiplication (fast)
start = time.time()
result_arr = arr1 * arr2
print(f"NumPy: {time.time() - start:.4f}s")

# NumPy is 10-100x faster!
⚠️ Common Mistakes
❌
Using Python lists for numerical computing.
✔ Use NumPy arrays for numerical operations. They're faster and more memory-efficient.
❌
Confusing shape and size.
✔ Shape is (rows, cols). Size is total elements (rows × cols).
❌
Not specifying dtype when needed.
✔ Specify dtype for memory efficiency: np.array([1,2,3], dtype=np.int32)
❌
Creating arrays with mixed types.
✔ NumPy arrays work best with homogeneous data. Mixed types slow everything down.
🎯 Interview Questions
Q
"What is NumPy and why is it important?"
"NumPy (Numerical Python) is the foundation of Python's data science ecosystem. It provides the ndarray object for efficient storage and operations on homogeneous data. NumPy is important because: 1) It's much faster than Python lists for numerical operations (implemented in C), 2) It uses less memory with contiguous storage, 3) It provides vectorized operations eliminating loops, 4) It's the foundation for Pandas, Scikit-learn, TensorFlow, and PyTorch."
Q
"What's the difference between a Python list and a NumPy array?"
"Python lists store references to objects anywhere in memory, support mixed types, and are slower for numerical operations. NumPy arrays store homogeneous data in contiguous memory, enabling vectorized operations, better CPU cache utilization, and significantly faster performance. NumPy arrays also provide shape/size attributes and support for advanced indexing and broadcasting."
