📖 The Story — Security Guard
Controlling the Flow

A security guard checks visitors. Sometimes they stop everything (break), skip one person (continue), or leave a section for later (pass).

Imagine a security guard checking visitors. A visitor is carrying prohibited items — the guard immediately stops checking everyone (break). Another visitor forgot an ID card — the guard skips that visitor and checks the next one (continue). The manager says "We'll implement VIP checking later" — the guard leaves that section empty (pass). Python's loop control statements work exactly like this.

🔄 break — Exit Loop Immediately
🔄 continue — Skip Current Iteration
continue skips the current iteration and immediately moves to the next one. Unlike break, the loop continues executing.

Example:
for number in range(1, 8):
  if number == 5:
    continue
  print(number)

Output: 1, 2, 3, 4, 6, 7 (only 5 is skipped)

Real-world use: Processing files — skip corrupted files without stopping the entire upload.

⏸️ pass — Placeholder
pass is a placeholder statement that does nothing. Python doesn't allow empty blocks, so pass is used when syntax requires a statement but no action is needed.

Example:
def login():
  pass # Will implement later

Real-world use: Creating the structure of a program before implementing the details. Teams often create function and class skeletons with pass.
🔄 else with Loops
else with loops is a unique Python feature. The else block executes only if the loop finishes normally (without hitting break).

Example — Search:
products = ["TV", "Laptop", "Phone"]
search = "Tablet"
for product in products:
  if product == search:
    print("Found")
    break
else:
  print("Not Found")

Output: "Not Found" (because the loop never hit break)
Benefit: No need for extra Boolean variables to track whether an item was found!
🔧 Practical Loop Patterns
🔍 Search
for item in items: if found: break
✅ Validation
Skip invalid data with continue
🔄 Retry
while attempts <= 3: if login(): break
🌐 Server
while True: receive_request()
⚠️ Common Beginner Mistakes
❌
Confusing break and continue.
✔ break stops the entire loop. continue skips only the current iteration. Remember: break = emergency stop, continue = skip one step.
❌
Using pass instead of continue.
✔ pass does nothing (placeholder). continue skips the rest of the current iteration and moves to the next one.
❌
Expecting else to execute after break.
✔ The else block runs only if the loop completes normally. If break is used, else is skipped.
❌
Creating unnecessary Boolean variables.
✔ Instead of found = False and checking it after the loop, use for...else which handles this elegantly.
🎯 Interview Questions
Q
"What is the difference between break and continue?"
"break immediately exits the loop entirely. continue skips only the current iteration and proceeds to the next one. Use break when continuing the loop serves no purpose (e.g., item found in search). Use continue when you want to skip specific cases but continue processing others (e.g., skip corrupted files)."
Q
"What is the purpose of pass?"
"pass is a placeholder statement that tells Python to do nothing. It is used when syntax requires a statement but no action is needed, such as when defining a function or class skeleton that will be implemented later."
Q
"How does else work with loops?"
"The else block executes only if the loop completes normally without hitting a break statement. This is useful for search operations—if the item is found, we break and skip the else. If the item is not found, the else block executes, indicating the item was not in the collection."
