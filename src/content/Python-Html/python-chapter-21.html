📖 The Story — Language Translator
Different Formats

Different situations require different ways of expressing the same information. Data formats are like languages - each has its own use case.

Imagine you need to share a recipe. For a spreadsheet, you'd use CSV. For a web app, you'd use JSON. For a document with formatting, you might use XML. Each format has strengths: CSV is simple and human-readable, JSON is lightweight and perfect for web APIs, XML is verbose but highly structured and supports complex hierarchies. Python's standard library supports all three formats natively.

🔧 CSV Example
Reading CSV:

import csv

with open("data.csv", "r") as file:
  reader = csv.reader(file)
  for row in reader:
    print(row)

Writing CSV:

with open("output.csv", "w") as file:
  writer = csv.writer(file)
  writer.writerow(["Name", "Age", "City"])
  writer.writerow(["Alice", 22, "NYC"])
🔧 JSON Example
Reading JSON:

import json

with open("data.json", "r") as file:
  data = json.load(file)
  print(data["name"])

Writing JSON:

data = {"name": "Alice", "age": 22}
with open("output.json", "w") as file:
  json.dump(data, file, indent=2)
⚠️ Common Mistakes
❌
Forgetting to handle encoding.
✔ Always specify encoding="utf-8" when working with files containing special characters. Example: open("file.csv", encoding="utf-8")
❌
Not using the csv module for CSV files.
✔ Don't parse CSV manually with split(). Use the csv module which handles edge cases like quoted fields and commas inside values.
❌
Using XML for simple data.
✔ For simple data, prefer JSON or CSV. XML is overkill for most modern applications.
🎯 Interview Questions
Q
"When would you use CSV vs JSON?"
"Use CSV for tabular data that needs to be opened in Excel or spreadsheets. Use JSON for web APIs, configuration files, or when you need nested data structures. CSV is simpler but less flexible. JSON supports nested structures and is the standard for web APIs."
Q
"What is serialization?"
"Serialization is the process of converting data structures (like dictionaries or objects) into a format that can be stored or transmitted (like JSON or XML). Deserialization is the reverse process - converting the formatted data back into data structures."
