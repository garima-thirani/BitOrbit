📖 The Story — The Calculator
Buttons and Operations

Python operators are like the buttons on a calculator. They tell Python what operation to perform on values.

Imagine a calculator with buttons: 7, +, 3, =. The calculator isn't smart because of the numbers—it's smart because of the operations. Python operators are the buttons that tell Python what operation to perform. An operator is a symbol that performs an operation on one or more values. For example, in 5 + 3, + is the operator and 5 and 3 are the operands.

⚖️ Comparison Operators
Comparison operators compare values and always return True or False.

== Equal to | != Not equal | > Greater than | < Less than | >= Greater or equal | <= Less or equal

Example: print(10 > 5) → True | print(5 == 10) → False

🔎 Membership Operators
Membership operators check whether an element exists in a sequence.

in → Returns True if element exists: 2 in [1,2,3] → True
not in → Returns True if element does NOT exist: 5 not in [1,2,3] → True

Useful with: Lists, Tuples, Sets, Dictionaries, Strings
📊 Operator Precedence (Highest to Lowest)
() ↓ ** ↓ * / // % ↓ + - ↓ Comparisons (== != > < >= <=) ↓ not ↓ and ↓ or
Example: 2 + 3 * 4 → 14 (not 20) because * has higher precedence than +.
Use parentheses to make precedence explicit: (2 + 3) * 4 → 20
⚠️ Common Beginner Mistakes
❌
Confusing = (assignment) with == (comparison).
✔ = assigns a value. == compares two values. Using if age = 18: instead of if age == 18: is a common error.
❌
Using is instead of == to compare values.
✔ Use == for value comparison. Use is for object identity. a == b checks if values are equal; a is b checks if they're the same object.
❌
Forgetting operator precedence.
✔ 2 + 3 * 4 = 14, not 20. Use parentheses to make your intent clear: (2 + 3) * 4.
❌
Misunderstanding floor division.
✔ 10 // 3 = 3, not 3.333. Floor division removes the decimal part, always rounding down.
🎯 Interview Questions
Q
"What is the difference between = and ==?"
"= is the assignment operator used to assign a value to a variable. == is the equality comparison operator that checks if two values are equal. Using = instead of == in a condition is one of the most common programming mistakes."
Q
"Explain the difference between == and is."
"== compares the values of two objects. is compares the identity (memory address) of two objects. Two objects can have equal values but be different objects in memory. For example, a = [1,2]; b = [1,2]; a == b is True, but a is b is False."
Q
"What is short-circuit evaluation?"
"Short-circuit evaluation means Python stops evaluating a logical expression as soon as the result is determined. For and, if the first condition is False, Python doesn't evaluate the second. For or, if the first condition is True, Python doesn't evaluate the second. This improves performance and can prevent errors like division by zero."
Q
"What is floor division and why is it useful?"
"Floor division (//) divides two numbers and returns the integer part, discarding the remainder. For example, 10 // 3 returns 3. It's useful for dividing items into groups, pagination, and any scenario where you need whole numbers."
