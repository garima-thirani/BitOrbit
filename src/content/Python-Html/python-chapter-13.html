📖 The Story — Sealed Envelope
Protected & Fast

A sealed envelope cannot be changed after sealing. This protects the contents and makes processing faster.

Imagine a sealed envelope containing important documents. Once sealed, the contents cannot be modified—this protects the data from accidental changes. Tuples work exactly like this. They are immutable, meaning once created, you cannot add, remove, or change elements. This immutability makes them safer for protecting data and faster for Python to process.

🔧 Tuple Packing & Unpacking
Packing: Combining multiple values into a tuple.
point = (10, 20) # Packing

Unpacking: Extracting values from a tuple into variables.
x, y = point # x=10, y=20

Swapping:
a, b = 1, 2
a, b = b, a # a=2, b=1
⚠️ Common Mistakes
❌
Trying to modify a tuple.
✔ Tuples are immutable. t[0] = 5 raises TypeError. If you need to change data, use a list instead.
❌
Forgetting the comma in single-element tuples.
✔ (5) is just an integer in parentheses. Use (5,) for a single-element tuple.
❌
Using tuples when lists are more appropriate.
✔ Use tuples for fixed data. Use lists when you need to add/remove items.
🎯 Interview Questions
Q
"What is the difference between a tuple and a list?"
"Tuples are immutable (cannot be changed after creation) while lists are mutable. Tuples are faster and use less memory. Use tuples for fixed data that shouldn't change, and lists for data that needs to be modified."
Q
"What is tuple unpacking?"
"Tuple unpacking allows you to extract values from a tuple into multiple variables in a single statement. Example: x, y = (10, 20) assigns 10 to x and 20 to y. It's commonly used for swapping variables: a, b = b, a."
