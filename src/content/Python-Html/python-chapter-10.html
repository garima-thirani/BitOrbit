📖 The Story — Factory Assembly Line
Pipeline Processing

Each station performs one job, receives input, processes it, and passes the result forward.

Imagine a car factory assembly line. Each station performs exactly one job: Cutting, Painting, Quality Check, Packaging. Each station doesn't know about the others—it simply receives an input, processes it, and passes the result forward. Functional programming follows the same idea. Instead of writing one huge function, we build many small functions and connect them together using tools like map(), filter(), and reduce().

🔧 Closure Example
Closure: A function that remembers variables from its enclosing scope even after the outer function has finished executing.

def multiplier(x):
  def multiply(y):
    return x * y
  return multiply

double = multiplier(2)
print(double(5)) # 10

Use cases: Function factories, data hiding, callbacks, decorators.
🎯 Interview Questions
Q
"What is a lambda function?"
"A lambda function is a small anonymous function written in a single expression. Syntax: lambda arguments: expression. Use lambda only for short operations. Complex logic should use def."
Q
"Explain map(), filter(), and reduce()."
"map() transforms every element. filter() selects elements based on a condition. reduce() combines all elements into one value. map and filter are built-in; reduce is in functools."
Q
"What is a closure?"
"A closure is an inner function that remembers variables from its outer function even after the outer function has returned. Closures form the foundation for decorators, one of Python's most powerful features."
