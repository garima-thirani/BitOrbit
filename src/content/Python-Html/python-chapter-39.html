📖 The Story — Restaurant Kitchen
Multiple Tasks

One chef doing all tasks is slow. Multiple chefs working simultaneously get things done faster. This is concurrency.

Imagine a restaurant where one chef must cook, wash dishes, pack orders, and answer phones. Customers wait forever. Now imagine four chefs, each handling one task simultaneously. Everything happens in parallel. Programs face the same problem. Concurrency allows a program to perform multiple tasks at the same time, keeping applications responsive.

🔧 Creating Threads Example
Basic threading example:

import threading
import time

def task(name):
  print(f"{name} started")
  time.sleep(2)
  print(f"{name} finished")

# Create threads
t1 = threading.Thread(target=task, args=("Thread-1",))
t2 = threading.Thread(target=task, args=("Thread-2",))

# Start threads
t1.start()
t2.start()

# Wait for completion
t1.join()
t2.join()
print("All threads completed")
🔧 Lock Example
Thread synchronization with Lock:

import threading

balance = 100
lock = threading.Lock()

def withdraw(amount):
  global balance
  with lock:
    if balance >= amount:
      balance -= amount
      print(f"Withdrew {amount}, balance: {balance}")

# Create threads
t1 = threading.Thread(target=withdraw, args=(30,))
t2 = threading.Thread(target=withdraw, args=(40,))
t1.start()
t2.start()
t1.join()
t2.join()
⚠️ Common Mistakes
❌
Calling thread.run() instead of thread.start().
✔ run() executes in current thread. start() creates a new thread.
❌
Forgetting to call join().
✔ The main thread may finish before worker threads. Use join() to wait.
❌
Not protecting shared data with locks.
✔ Use locks when multiple threads modify shared state to prevent race conditions.
❌
Using threads for CPU-intensive tasks.
✔ Due to GIL, threads don't speed up CPU-bound work. Use multiprocessing instead.
🎯 Interview Questions
Q
"What is the difference between a Process and a Thread?"
"A Process is an independent program with its own memory space. A Thread is a lightweight execution unit inside a process that shares memory with other threads. Threads are faster to create and communicate, but processes provide better isolation and can run on multiple CPU cores."
Q
"What is the GIL and how does it affect threading?"
"The Global Interpreter Lock (GIL) is a mutex in CPython that allows only one thread to execute Python bytecode at a time. This means threading doesn't provide true parallelism for CPU-bound tasks. However, threads are still useful for IO-bound tasks where the GIL is released during waiting."
