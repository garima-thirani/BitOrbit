📖 The Story — The Warehouse
Labels and Boxes

Python variables are like labels attached to boxes in a warehouse. The label points to the box, not the other way around.

Imagine a warehouse with thousands of boxes. Each box contains something. Instead of remembering where every box is, we simply attach labels. Python variables behave exactly like these labels. A variable is simply a name (label) given to an object. When you write age = 25, the variable age is not the integer 25. It is merely a name pointing to the integer object.

🎯 Object Properties
Every Python object has three properties:
Value: The actual data stored (e.g., 25, "Hello", True)
Type: Determines what operations are allowed (use type() to check)
Identity: Unique memory address (use id() to check)

🔑 Python Keywords
Keywords are reserved words with predefined meanings. You cannot use them as variable names.

Examples: if, else, for, while, class, return, try, except, import, def, True, False, None

Incorrect: class = 10 ❌
Correct: class_name = "Python" ✅

⚠️ Common Beginner Mistakes
❌
Thinking variables store values.
✔ Variables store references to objects, not the values themselves. When you write x = 10, x points to the integer object 10.
❌
Forgetting that input() always returns a string.
✔ input() always returns str. Use int(input()) to get a number.
❌
Using keywords as variable names.
✔ if = 10 is invalid. Use if_condition = 10 instead.
❌
Confusing = (assignment) with == (comparison).
✔ = assigns a value. == compares two values.
🎯 Interview Questions
Q
"What is dynamic typing in Python?"
"Dynamic typing means the interpreter determines the data type of a variable at runtime, not at compile time. A variable can refer to different types of objects during its lifetime. For example, x = 10 makes x an integer, but later x = 'Python' makes it a string. This provides flexibility and faster development but can lead to runtime errors."
Q
"Are variables objects in Python?"
"No, variables are not objects. Variables are names (labels) that refer to objects. Everything in Python is an object—integers, strings, lists, functions, even classes. But variables are simply references pointing to those objects."
Q
"What does input() return?"
"input() always returns a string. If you need a number, you must explicitly convert it using int() or float(). For example: age = int(input('Enter age: '))"
Q
"What is the difference between implicit and explicit type casting?"
"Implicit type casting is performed automatically by Python when it's safe, like converting 5 to 5.0 in 5 + 2.5. Explicit type casting is done manually by the developer using functions like int(), float(), str(), and bool()."
Q
"What is None in Python?"
"None is Python's null value, representing the absence of a value. It is of type NoneType. It is commonly used as a default return value for functions that don't explicitly return anything, or as a placeholder for optional values."
