🎯 Interview Questions
Q
"What are Python decorators and when would you use them?"
"Decorators are functions that wrap other functions to add functionality without modifying them. Use cases: logging, timing, authentication, caching. Example: @app.route in Flask, @property in classes. They promote code reuse and separation of concerns."
Q
"Explain the GIL and its impact on threading."
"The Global Interpreter Lock (GIL) is a mutex that allows only one thread to execute Python bytecode at a time. This means threading in CPython doesn't provide true parallelism for CPU-bound tasks. For I/O-bound tasks, the GIL is released during I/O operations. For CPU-bound tasks, use multiprocessing."
