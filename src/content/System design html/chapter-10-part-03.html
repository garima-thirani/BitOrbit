📖 The Story — The Missing Message
Different Systems, Different Guarantees

Alice sends Bob "Hello!" but Bob doesn't see it for 10 seconds. Is the system broken?

Alice sends Bob "Hello!" using a messaging application. Alice immediately opens the conversation and sees "Hello!". Bob opens the same chat and sees nothing. Ten seconds later, the message finally arrives. Question: Is the system broken? No. The application uses Eventual Consistency. Different systems provide different guarantees about when data becomes visible. Understanding these guarantees is critical for designing distributed systems.

🎯 What is a Consistency Model?
Consistency Model: Defines the guarantees a system provides after a write operation. It answers: "If data changes, when can readers observe that change?" Different models offer different trade-offs between latency, availability, and correctness.

🔄 Quorum Reads & Writes
Quorum: When R + W > N (where R = read quorum, W = write quorum, N = total replicas), read and write sets overlap, providing strong consistency. Example: N=3, R=2, W=2. Write succeeds on 2 replicas, read queries 2 replicas. At least one has latest data.
🏭 Production Examples
Real World

Google Spanner vs Cassandra

Google Spanner: Uses Strong Consistency with TrueTime clocks. All reads see latest writes. Perfect for financial transactions.

Cassandra: Uses Eventual Consistency with tunable quorum. Developers choose consistency level per query (ONE, QUORUM, ALL). Perfect for high availability.

🎯 Interview Callout
Q
"What's the difference between Strong and Eventual Consistency?"
"Strong consistency guarantees every read returns the latest successful write immediately. Eventual consistency allows temporary stale reads but guarantees all replicas will converge if no new updates occur. Strong consistency prioritizes correctness, while eventual consistency prioritizes availability and scalability."
🧠 Memory Trick
Strong = Always correct. Eventual = Eventually correct. Causal = Cause before effect. Choose the weakest model that satisfies business needs.
