📖 The Story — Two Leaders
The Split-Brain Problem

A banking application runs three database servers. Server A is the leader. Suddenly, a network partition occurs. Server A believes it's still leader. Server B cannot contact A, so it elects itself leader. Now two leaders exist. Both accept writes. Balances diverge. Who is correct?

Neither server can decide alone. They need Consensus. Consensus algorithms ensure that despite failures, every healthy node agrees on critical decisions: who is the leader, what is the transaction order, and what is the cluster configuration.

🎯 What is Consensus?
Consensus: A process by which multiple computers agree on one decision when they cannot completely trust the network. Consensus solves leader election, cluster membership, transaction ordering, and distributed locking.

🔄 Raft Node States
Raft States: Every node is either Follower (default, accepts leader messages), Candidate (requests votes during election), or Leader (handles all writes, replicates to followers). Exactly one leader normally exists.
✅ Leader Election Flow
Election Process: Leader sends heartbeats → Followers wait → Heartbeat stops → Timeout expires → Followers become Candidates → Request votes → Majority wins → New leader elected. Automatic failover without manual intervention.
🏭 Production Examples
Real World

etcd, CockroachDB & Kubernetes

etcd: Uses Raft consensus. Stores Kubernetes cluster state. Every deployment, pod, service depends on etcd consensus.

CockroachDB: Each data range uses Raft for leader election and replication. Automatic failover, strong consistency.

Kubernetes: Uses etcd (Raft-based) for cluster state, leader election, and configuration management.

🎯 Interview Callout
Q
"Why is Raft preferred over Paxos?"
"Both provide strong consensus guarantees, but Raft was designed to be easier to understand, implement, and debug. This simplicity has led to widespread adoption in etcd, CockroachDB, and Kubernetes. Paxos is mathematically elegant but notoriously difficult to implement correctly."
🧠 Memory Trick
Quorum = Majority. Raft = Leader + Followers. Election = Timeout + Votes. Consensus prevents split-brain.
