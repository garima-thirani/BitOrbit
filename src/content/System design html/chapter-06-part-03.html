📖 The Story — The Local Library
Why CDNs Exist

Popular books are stored in local libraries, not just the central archive.

Imagine a country with one central library in the capital. To borrow a book, everyone must travel to the capital. The solution? Copy popular books to local libraries across the country. Now readers in Mumbai access a local copy instead of traveling to Delhi. CDNs work exactly the same way. They copy your website's static content to edge servers worldwide.

🎯 Why CDNs Matter

Without a CDN: User in Japan → Server in USA → 300ms latency. With a CDN: User in Japan → CDN Edge in Tokyo → 20ms latency. The improvement is dramatic.

📐 What is a CDN?
CDN (Content Delivery Network): A geographically distributed network of proxy servers that cache content at edge locations. When a user requests content, the CDN serves it from the nearest edge server instead of the origin.
🏛 CDN Architecture
CDN Flow: User → Edge Server → (Hit or Miss) → Origin if needed
🔄 How CDNs Work
User Requests: https://example.com/image.jpg ↓ DNS Resolution → Nearest CDN Edge ↓ CDN Checks Cache ├── Hit → Return image (fast!) └── Miss │ Fetch from Origin │ Cache at Edge │ Return to User
