📖 The Story — The AWS Region Outage
When an Entire Region Goes Offline

A large e-commerce company deploys its entire application inside one AWS Region. One morning, a major power failure affects the entire region. Millions of users cannot place orders. Revenue drops to zero.

The application was highly available inside one region, but not across regions. This is why global companies build Multi-Region Architectures. When one region fails, traffic automatically shifts to another. Users continue shopping. The business survives.

🎯 What is Multi-Region Architecture?
Multi-Region Architecture: Deploying applications and data across multiple geographic regions. Provides lower latency for global users, higher availability through regional failover, and disaster recovery against regional failures.

🔄 Geo-Replication Strategies
Synchronous: Write must complete in every region before returning. Strong consistency, high latency. Asynchronous: Write completes locally, other regions update later. Low latency, eventual consistency. Most global systems use asynchronous replication.
✅ Global Load Balancing
Global Load Balancer: Routes users to the nearest healthy region. Uses DNS-based routing, health checks, and latency measurement. If a region fails, traffic automatically shifts to another region. Examples: AWS Route53, Cloudflare Load Balancer.
🏭 Production Examples
Real World

Netflix & Amazon

Netflix: Deploys Active-Active across multiple AWS regions. Users route to nearest region via DNS. Content cached in Open Connect CDN. If one region fails, traffic shifts automatically.

Amazon: Uses Active-Passive for critical services with automated failover. Regional databases with async replication. RTO under 5 minutes for critical systems.

🎯 Interview Callout
Q
"When would you choose Active-Active over Active-Passive?"
"Choose Active-Active when users are globally distributed and low latency is critical. Multiple regions simultaneously serve traffic, improving availability and reducing latency. Active-Passive is simpler and better suited when disaster recovery is the primary goal and cost optimization matters."
🧠 Memory Trick
Active-Passive = Simple DR. Active-Active = Global Performance. Geo-Replication = Data Sync. RPO = Data Loss. RTO = Downtime.
