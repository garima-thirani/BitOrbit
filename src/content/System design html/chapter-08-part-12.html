🏢 Amazon - Order Processing Platform
E-Commerce at Scale

Millions of orders/day with complete event traceability.

Primary Event: OrderCreated
Architecture: REST API → Order Service → PostgreSQL → Transactional Outbox → Kafka → 20+ Consumer Groups
Consumers: Inventory, Shipping, Fraud, Analytics, Recommendations, Warehouse, Billing, Customer Timeline, Search, ML
Key Features: CQRS with Redis/Elasticsearch read models, Event Sourcing for financial domains, Replay for disaster recovery, Schema Registry for 200+ services
Technology: Kafka, PostgreSQL, Redis, Elasticsearch, ClickHouse, Spark, Iceberg

🏢 Uber - Ride Platform
Real-Time Transportation

Millions of rides/day with continuous GPS streaming.

Primary Event: RideRequested
Architecture: REST API → Ride Service → PostgreSQL → Transactional Outbox → Kafka → Consumer Groups
Consumers: Driver Matching, Pricing, Payments, Driver Earnings, Fraud, Notifications, Maps, Analytics, ML
Key Features: Partition by Ride ID for ordering, Location events (1M+ events/sec), Dynamic surge pricing, Heat maps, CQRS for dashboards
Technology: Kafka, PostgreSQL, Redis, ClickHouse, Elasticsearch, gRPC

🏢 Netflix - Streaming Platform
Billions of Playback Events

300M+ users with personalized recommendations.

Primary Event: PlaybackStarted
Architecture: Playback Service → Kafka → Consumer Groups
Consumers: Recommendations, Trending, Billing, Analytics, Watch History, ML Pipeline, Content Ranking
Key Features: ML feature extraction, Continue Watching sync, Multi-device synchronization, Replay for algorithm updates
Technology: Kafka, Cassandra, Redis, Feature Store, Spark, Iceberg

🏢 LinkedIn - Activity Platform
1B+ Members Activity Stream

Every user action powers multiple products.

Primary Event: ActivityCreated
Architecture: Activity Service → Kafka → Consumer Groups
Consumers: Feed Ranking, Search, Notifications, Ads, Analytics, Recommendations, Fraud
Key Features: Feed generation with 100+ ranking signals, Search index updates, Ad targeting, Profile views tracking
Technology: Kafka, Elasticsearch, Redis, ClickHouse, ML Pipeline

🏢 WhatsApp - Messaging Platform
2B Users, 100B Messages Daily

Ordered messaging with end-to-end encryption.

Primary Event: MessageCreated
Architecture: WebSocket → Messaging Service → Kafka → Storage + Delivery
Key Features: Partition by Conversation ID for ordering, Offline sync via replay, Read receipts, Push notifications, Multi-device support
Technology: Kafka, Redis (presence), Object Storage (media), Push Notification Infrastructure
