📋 Quick Revision Notes

Redis Cluster & Data Structures

Redis Cluster distributes data across multiple masters using 16,384 hash slots. Each master handles a subset of data. Replicas provide high availability. Redis supports rich data structures: Strings, Hashes, Lists, Sets, Sorted Sets, Bitmaps. Redis Cluster = Multiple Masters + Replicas + Hash Slots.

Redis vs Memcached

Redis: Rich features, persistence, replication, multiple data structures. Memcached: Simple, fast, multi-threaded, memory-efficient. Redis has largely replaced Memcached in modern systems due to its versatility. Choose Memcached only for pure, simple caching.

CDN Fundamentals

CDNs cache content at edge locations worldwide. Benefits: Lower latency, global reach, DDoS protection, cost savings. Cache control headers (Cache-Control, Expires, ETag) control how CDNs cache content. CDN = Content at the Edge.

Edge Caching & Optimization

Advanced CDN strategies: Edge computing (run code at edge), Cache warming (preload content), Smart invalidation (purge by URL/tag), Geographic routing. Modern CDNs are distributed computing platforms, not just file servers.

Multi-Tier Caching

Four cache layers: L1 Browser, L2 CDN, L3 Redis, L4 Database. Each layer reduces load on deeper layers. Multi-tier caching is essential for high-performance systems. L1 → L2 → L3 → L4. Each layer catches what the previous one misses.

Cache Warming

Preload data into cache before users request it. Warm at: Application startup, before traffic spikes, after restarts, periodically. Strategies: Analytics-based, predictive, scheduled, event-driven. Warm Before Traffic. Predict Demand. Monitor Hit Rates.

Facebook News Feed

Multi-tier caching: Browser, CDN, Redis, Database. Fanout: Push for normal users, pull for celebrities. Ranking: Recency, engagement, relationship, user behavior. Handle viral content with dedicated caches and CDN. Feed = Cache + Fanout + Rank.

💡 Flashcards
Q: What is Redis Cluster?
A: Distributed Redis with multiple masters, replicas, and hash slots for horizontal scaling
Redis Cluster distributes data across masters using 16,384 hash slots, enabling horizontal scaling.
Q: Which Redis data structure is best for a leaderboard?
A: Sorted Set — maintains elements sorted by score
Sorted Sets automatically maintain elements in score order, perfect for rankings.
Q: What is the main benefit of a CDN?
A: Reduces latency by serving content from nearby edge locations
CDNs cache content at edge locations worldwide, reducing distance and improving response times.

🧪 Final Quiz
1. Why would you choose Redis over Memcached for a modern application?
A) Redis is faster
B) Redis offers more features: data structures, persistence, replication
C) Redis uses less memory
D) Redis is simpler
Redis provides rich data structures, persistence, replication, and more — making it more versatile than Memcached for most use cases.
2. What is the main benefit of multi-tier caching?
A) Reduces code complexity
B) Each layer reduces load on deeper layers, improving overall performance
C) Eliminates need for databases
D) Increases memory usage
Multi-tier caching distributes load across layers. Each layer serves what it can, reducing database pressure and improving latency.
